# Practical 08 - Privacy Breach Response Plan

## Aim
To prepare a response plan for a personal-data breach.

## Response stages
1. Detect and verify
2. Contain
3. Preserve evidence
4. Assess scope and risk
5. Notify appropriate stakeholders when required
6. Remediate
7. Recover
8. Conduct lessons learned

## Result
A written response plan helps an organization respond consistently instead of improvising during an incident.
