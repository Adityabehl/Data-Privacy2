# Data Privacy Practicals

A collection of practical exercises for the Data Privacy course (GE6d/DSE: Data Privacy).

## Practicals

1. Data Privacy Audit
2. Privacy Impact Assessment (PIA)
3. Regulation Compliance
4. Cryptography
5. Data Anonymization
6. Privacy Policy Analysis
7. Privacy-Enhancing Technologies (PETs)
8. Privacy Breach Response Plan
9. Ethical Considerations in Data Privacy
10. Data Privacy Case Studies

## Repository structure

Each practical contains a README explaining the aim, theory, procedure, expected result, and conclusion.
