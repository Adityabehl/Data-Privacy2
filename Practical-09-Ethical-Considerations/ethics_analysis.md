# Ethical Analysis

## Case
A college wants to install continuous facial-recognition cameras to improve campus security.

### Potential benefits
- Faster identification of security incidents
- Possible deterrence of unauthorized access
- Automated investigation support

### Ethical concerns
- Continuous surveillance
- Lack of meaningful consent
- False matches
- Bias across demographic groups
- Function creep
- Long-term retention
- Chilling effect on student behavior

### Questions
1. Is continuous identification necessary?
2. Is there a less intrusive alternative?
3. Who can access the data?
4. How long is it retained?
5. How are false matches handled?
6. Is there independent oversight?

## Conclusion
Security objectives should be balanced against necessity, proportionality, transparency and the rights and interests of affected people.
